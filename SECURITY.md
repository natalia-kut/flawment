# Security policy

Only the latest version on `main`, deployed at
[flawment.vercel.app](https://flawment.vercel.app), is supported.

## Reporting a vulnerability

Please do not open a public issue. Use
[private vulnerability reporting](https://github.com/natalia-kut/flawment/security/advisories/new)
and describe the problem, the steps to reproduce it and its impact.

Test against a local installation with your own data, not against the deployed
application or other people's accounts.

The credentials in `.env.example`, `docker-compose.yml` and the sample data are for
local development only.
